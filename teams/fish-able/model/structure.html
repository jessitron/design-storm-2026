Call rules & implementation status

Arrows show tier direction, not every dependency. Journey orchestration can call CollectionSystem domain queries and coordinate Reading requests in Tier 1. Returning a result is not an upward call. Domain never imports or invokes orchestration.

Only CollectionSystem, Node and Leg are implemented. Other boxes describe proposed responsibilities, not class signatures. Direct topology queries need no orchestration wrapper. Anchor, fabrication, replay and SNOTEL decisions remain deferred.
